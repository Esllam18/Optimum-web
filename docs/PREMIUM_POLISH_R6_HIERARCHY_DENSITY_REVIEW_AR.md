# Optimum 6.9.1 — Premium Polish R6

**الهدف:** Hierarchy + Density + Repetition pass بعد مراجعة R5 Live.

## ما ظهر في R5 Live
- شريط قرارات الإدارة كان يحجز مساحات فارغة عند وجود قرار واحد.
- Attention Inbox الفارغ كان أكبر بصريًا من أهميته.
- التحية العربية مع اسم لاتيني احتاجت Bidi isolation.
- صفحة Tasks كررت «المهام» في الـTopbar والـHero.
- Quick Add وDaily rail كانا ينافسان قائمة العمل أكثر من اللازم.

## ما تغير في R6
- Hero الإدارة أصبح أكثر كثافة.
- التحية أصبحت structured/Bidi-safe.
- Executive brief أصبح adaptive حسب عدد الإشارات.
- Empty Attention أصبح compact inline state.
- Focus rows أخف مع الحفاظ على status/priority/due.
- Hero المهام أصبح «مركز التنفيذ / Execution center».
- Quick Add أخف بصريًا مع بقاء كل الإمكانيات.
- Daily rail أضيق ويخدم قائمة المهام بدل منافستها.
- Responsive محدث بدون تغيير أي backend/RPC/permission contract.
