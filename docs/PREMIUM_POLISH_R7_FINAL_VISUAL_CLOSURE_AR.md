# Optimum 6.9.1 — Premium Polish R7

## الهدف
إغلاق آخر ملاحظات الـLive visual review بدون إضافة Features جديدة.

## ما تغير
- شريط قرارات الإدارة أصبح compact ويكيّف نفسه مع عدد القرارات، خصوصًا حالة القرار الواحد.
- Empty state لصندوق الانتباه أصبح سطرًا هادئًا قابلًا للفتح بدل Card كبيرة فارغة.
- هوية Optimum داخل Dashboard Hero أصبحت مدمجة في السطح وأقل شبهًا بالـsticker.
- Quick Add في المهام أصبح command-like وأقل ارتفاعًا.
- Daily rail أصبح عنصرًا مساعدًا أهدأ، مع تقليل وزنه البصري.
- Sidebar hover/active states وspacing/typography تم توحيدهم نهائيًا.
- لا تغييرات على Backend أو RPCs أو Permissions أو نماذج البيانات.
